# Bundled Tesseract language data

`eng.traineddata` is the English model for the Tesseract OCR engine
(from the official tesseract-ocr/tessdata project, Apache License 2.0).

The engine itself comes from the `tesserocr` pip package listed in
`requirements.txt`, which ships Tesseract 5 for Windows, macOS and Linux.
Together they give working OCR with no separate Tesseract install.
